# Source and licence policy

What `content-v2/indexes/source-registry.json` records, how each field is derived, and why almost every record has no licence.

## The registry

Generated by `scripts/build-source-registry.mjs`. 136 records:

- **24 collection records** (`collection:<value>`) — one per distinct source collection the importers attributed material to.
- **112 reference-host records** (`reference-host:<hostname>`) — one per distinct hostname cited anywhere in the corpus.

`generatedOn` is copied from `content-v2/catalog.json` (`2026-08-15`) rather than read from the clock, so the file regenerates byte-identically. `scripts/validate-source-registry.mjs` enforces that.

## Record shape

```
{ id, title, authorOrOrganization?, provider?, url?, license?, usageType?, attributionRequired?, importedAt?, notes? }
```

`notes` is present on every record and always states the evidence behind the record, including the absence of a licence.

## Derivation

### Collection records

| Field | Rule |
| --- | --- |
| `id` | `collection:` + the raw value |
| `title` | Raw value, `-`/`_` replaced by spaces, each word's first character upper-cased. The raw value is repeated in `notes`, so the transform is reversible. |
| `usageType` | `"adaptation"` when every item attributed to the collection sets `importedWithoutRewriting === true`. True for all 24 collections. |
| `importedAt` | Earliest `YYYY-MM-DD` prefix of a `provenance.importBatch`, or earliest question `provenance.lastVerified`. Omitted when neither exists — 11 of the 24 collections have no date evidence at all. |
| `provider`, `url` | Omitted. A collection slug is not a publisher and is not a URL. |

Values come from topic `provenance.sourceCollection` and question `sourceCollection`. 494 sleep-technology questions carry no top-level `sourceCollection` but do carry `provenance.sourceCollection` (`rpsgt-500-questions`); that value is read as a documented fallback so a real source is not silently dropped. The fallback is recorded in the file's own `derivationRules`.

### Reference-host records

| Field | Rule |
| --- | --- |
| `id` | `reference-host:` + hostname parsed from the reference URL |
| `provider` | The hostname |
| `url` | `https://<hostname>` |
| `title` | The most frequent reference `text` seen for that host, **verbatim**, ties broken by the lexicographically smallest text |
| `notes` | How many distinct reference URLs resolve to that host, plus the licence position |

Titles are copied character-for-character from repository text. Some read awkwardly — a full citation string rather than a publisher name. That is deliberate: rewriting them into tidy publisher names would be authoring, and the tidy name would no longer be traceable to anything.

## The licence position

**A licence is recorded only when that exact string appears in repository text for that same source.** Licences are never inferred from a hostname, a top-level domain, a publisher name or general knowledge about an organisation's usual terms.

Two records carry a licence:

| Record | Licence | Evidence |
| --- | --- | --- |
| `reference-host:openstax.org` | `CC BY 4.0` | Reference text: `OpenStax. *Anatomy and Physiology 2e*. Rice University, CC BY 4.0. https://openstax.org/...` |
| `reference-host:opentextbc.ca` | `CC BY 4.0` | Reference text: `BCcampus. *Anatomy and Physiology 2e*. OpenStax-derived, CC BY 4.0. https://opentextbc.ca/...` |

The other 134 records carry no `license`, and each says so in `notes`.

This includes sources whose terms a reader may believe they know. 45 of the 112 hosts are `.gov` domains — `www.cdc.gov`, `medlineplus.gov`, `www.nih.gov` and the rest, carrying 470 distinct reference URLs between them — and US government works are frequently public domain. But that is knowledge from outside this repository, it varies by page and by embedded third-party material, and it is not what the corpus says. So the field stays empty. `scripts/validate-source-registry.mjs` fails if any record claims a licence with no matching literal in repository text.

If more than one distinct licence string were found for a host, no licence would be recorded and `notes` would state the ambiguity. That case does not currently arise.

### `attributionRequired`

Emitted as `true` only for records whose literal licence string is a CC BY variant, because attribution is that licence's defining condition. Omitted everywhere else, including for every source with no licence evidence — omission means "unknown", not "no attribution needed". The validator rejects `attributionRequired` on any record with no `license`.

### `authorOrOrganization`

Omitted on every record. The corpus stores collection slugs and citation text, not a verified author or rights holder. Parsing an author out of a citation string would produce a plausible-looking value that no field in the repository actually asserts.

## What this policy does not do

- It does not clear any source for reuse. An empty `license` means the question was not answered here, not that the answer is permissive.
- It does not verify that a cited URL still resolves or still says what the citation claims. Nothing in this repository re-checks upstream sources.
- It does not assert that reuse of the collections is licensed. `usageType: "adaptation"` records *how the importer handled the text* (`importedWithoutRewriting`), not what rights were obtained.

Anything that needs a real answer — a licensing question, a takedown, a commercial-use decision — needs a human to look at the upstream source. The registry tells that human exactly which sources to look at and how much material depends on each one.

## Rebuilding

```
node scripts/build-source-registry.mjs
node scripts/validate-source-registry.mjs
```

Rebuild the registry before `scripts/build-topic-metadata.mjs`: every topic's `sourceIds` must resolve to a record, and `scripts/validate-metadata.mjs` checks it.
