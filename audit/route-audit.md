# Route audit

Result: PASS

All 16 registered route patterns were validated. The production browser audit checked 376 unique routes and deep links, while the GitHub Pages build generated 370 canonical route entry points plus the root document. Coverage includes all subjects, 121 lessons, 111 note details, every available lesson question collection, search, downloads, help, error, 404, and invalid routes.

Question-only Chemistry lessons load directly and expose their practice collection. Their nonexistent note detail URLs render the 404 experience and are not generated as static entry points. Every representative page has one main landmark and one H1, an appropriate title, working navigation, and no horizontal overflow or browser/network error.
