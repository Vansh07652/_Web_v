# Clinical Nursing Skills

## Book Overview

Clinical Nursing Skills is organized as an OpenStax learning resource with a sequence of chapters that develop foundational ideas, connections, and applications. This study library follows the local public outline and provides focused, original review material rather than a replacement for the textbook.
