# OPENSTAX STUDY-NOTES WRITING REQUIREMENTS (canonical)

Author ORIGINAL educational study-guide content for every topic file in this repository. The current
topic files are generic boilerplate templates that do NOT teach real content — they must be
REWRITTEN with real, subject-specific lessons.

## Format
`<subject>/<book-slug>/chapter-<number>-<chapter-slug>/<topic-number>-<topic-slug>.md`
(e.g., `science/biology-2e/chapter-01-the-study-of-life/01-themes-and-concepts-of-biology.md`)

## Required sections per topic file (in this order)
1. H1 title + short metadata blockquote (book/chapter/topic links, matching existing frontmatter style)
2. A clear ORIGINAL explanation of the topic in your own words (real subject matter)
3. Why the topic matters (science, healthcare, nursing, exams, patient safety, or real-world application)
4. Core concepts broken into readable `###` subsections (real content, not generic advice)
5. `## ELI-10: Explain Like I'm 10` — 2-5 simple, accurate sentences
6. `## High-Yield Points` — most important facts, relationships, safety points, exam concepts
7. `## Key Terms` — table (Term | Plain-language definition | Why it matters)
8. At least one ORIGINAL example, scenario, analogy, process walkthrough, or clinical-reasoning illustration
9. `## Common Confusions` — table (Do not confuse | With | Difference) incl. test traps
10. `## Quick Review` — 4-6 self-review questions with answers hidden in a GitHub-compatible `<details>` block
11. `## Related Topics` — links to sibling topic files and the chapter README (use existing filenames)

## Standards
- Original study guide, NOT copied textbook text, NOT generic meta-template text.
- Student-friendly but accurate; define specialized vocabulary before relying on it.
- ~2-3 pages per topic; never exceed 5 pages.
- GitHub-compatible Markdown (tables, `<details>`, relative links).
- Keep the existing YAML frontmatter and file naming; update `status: "complete"` only when truly complete.
- Preserve the existing chapter/README structure and links.

## Safety rules by domain
- Nursing/medical: educational drafts only. No invented clinical facts, doses, guidelines,
  contraindications, lab ranges, or treatment recommendations. Flag unsupported/conflicting claims
  for source/SME review. Person-first language. Scope-of-practice and institutional variation noted.
- Science: accurate, standard terminology; equations with defined variables; no unsafe laboratory
  instructions; note model limitations.

## Source notes
- Structure mirrors OpenStax public textbook outlines (openstax.org). Content must be original
  educational material written from subject knowledge, not copied from the textbooks.
- Source-validation requirement: ENABLED for all content (flag anything unsupported).
