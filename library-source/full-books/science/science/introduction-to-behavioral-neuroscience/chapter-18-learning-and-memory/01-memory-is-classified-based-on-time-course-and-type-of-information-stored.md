# Memory is Classified Based on Time Course and Type of Information Stored

> **Book:** [Introduction to Behavioral Neuroscience](../../README.md)  
> **Chapter:** [Chapter 18: Learning and Memory](../README.md)  
> **Topic:** 1  
> **Source structure:** OpenStax public textbook outline

## Overview

Memory is not one thing. The phone number you hold in your head for five seconds, the route you drive home without thinking, and your memory of your first day of college feel completely different — and neuroscience agrees: they are supported by different brain systems and follow different rules. Researchers classify memories along two main dimensions. **By time course**, memories range from sensory memory (fractions of a second), through short-term and working memory (seconds to minutes), to long-term memory (days to a lifetime). **By type of information**, memories split into **explicit (declarative)** memories — facts and events you can consciously state — and **implicit (nondeclarative)** memories — skills and habits you express through performance without conscious recall. This two-axis classification is the organizing framework for the whole chapter: it explains why a person with amnesia can learn a new motor skill yet not remember learning it, and why a fact can feel "on the tip of your tongue" before it is gone.

## Why This Matters

Every act of learning — studying for an exam, rehabilitating after a stroke, teaching a patient to use an insulin pen — depends on which memory system is doing the work. Knowing the classification helps you predict what will be forgotten (unrehearsed short-term information), what will last (consolidated long-term memories), and what survives brain damage (implicit skills often persist when explicit recall fails). In clinical settings this distinction is huge: a person with amnesia may be unable to say what they ate for breakfast yet be fully able to relearn a physical routine. On exams, questions about the serial position effect, the capacity of short-term memory, or the difference between episodic and procedural memory all trace back to this framework. It is also the foundation for evidence-based study strategies: spacing, rehearsal, and elaboration all work because of how these systems transfer and consolidate information.

## Core Concepts

### The three operations: encoding, storage, and retrieval

Every memory, regardless of type, involves three processes. **Encoding** converts experience into a neural representation. **Storage** holds that representation over time. **Retrieval** brings stored information back into awareness or uses it to guide behavior. Failure at any stage looks like "forgetting" but has a different cause: encoding failure (never registered), storage decay (lost over time), or retrieval failure (stored but inaccessible — the "tip of the tongue" state). Interference, not just the passage of time, causes much everyday forgetting.

### Time course 1 — Sensory memory: the brief echo of experience

Sensory memory holds raw sensory information for a fraction of a second to a few seconds, long enough for the brain to decide what deserves further processing. Iconic (visual) memory is commonly cited as lasting roughly a third of a second to one second; echoic (auditory) memory lasts somewhat longer — commonly cited as 2–4 seconds — which is why you can "hear" the last words of a sentence someone said just before you stopped listening. Sensory memory has very large capacity but extremely brief duration, and almost all of it is lost unless attention captures it.

### Time course 2 — Short-term and working memory: the mental scratchpad

**Short-term memory (STM)** holds a small amount of information for about 15–30 seconds without rehearsal. Its famously cited capacity limit is 7 ± 2 items (the "magic number" from classic research by George Miller), though more recent work suggests it is often closer to 4 chunks. **Working memory** extends short-term memory by adding active manipulation — you are not just holding the digits, you are rearranging them. The classic working-memory model proposes multiple components: a **phonological loop** for verbal sound, a **visuospatial sketchpad** for images and spatial layouts, an **episodic buffer** that binds information together, and a **central executive** that directs attention among them. Working memory capacity is limited, and that limit is why multitasking degrades performance.

### Time course 3 — Long-term memory: the archive

**Long-term memory (LTM)** has essentially unlimited capacity and can last a lifetime. Information does not simply sit in LTM; it is **consolidated** — gradually stabilized and reorganized over hours, days, and years, with sleep playing a key role. The **serial position effect** illustrates the boundary between short- and long-term stores: when people recall a list, they remember the first items well (the **primacy effect**, because those got rehearsed into LTM) and the last items well (the **recency effect**, because those are still in short-term memory), while the middle items are forgotten most easily.

### Type 1 — Explicit (declarative) memory: facts and events you can state

**Explicit memory** is conscious and can be put into words. It comes in two flavors: **episodic memory**, your personal record of specific events tied to a time and place ("my graduation day"), and **semantic memory**, your general knowledge of facts independent of context ("graduation ceremonies happen in spring"). Both depend critically on the hippocampus and surrounding medial temporal lobe structures; damage there devastates the ability to form new explicit memories while leaving many other abilities intact.

### Type 2 — Implicit (nondeclarative) memory: knowing how, without knowing that you know

**Implicit memory** is expressed through behavior rather than conscious recollection. It includes **procedural memory** (riding a bike, tying shoes), **priming** (a word or image you saw earlier is easier to recognize later, even if you do not remember seeing it), and learned associations (classical and operant conditioning). Implicit memory does not require the hippocampus; it relies on structures like the cerebellum, basal ganglia, and amygdala depending on the task. The famous amnesia patient H.M. (Henry Molaison) could learn the motor skill of mirror tracing day after day with improving performance while having no conscious memory of ever having practiced — a clean demonstration that the two memory families are separate systems.

### How the systems interact

The classification is a map, not a set of rigid boxes. Information typically flows from sensory memory through working memory into long-term memory when it is attended, rehearsed, and meaningfully processed; but some implicit learning happens without ever passing through working memory at all. Amnesia dissociations (impaired explicit, intact implicit) show the systems can operate independently, yet in healthy brains they cooperate constantly — a skill you practice consciously (explicit) gradually becomes automatic (implicit) through repetition.

## ELI-10: Explain Like I'm 10

> Memory is like having three different boxes. A tiny "echo box" holds what you just saw or heard for a couple of seconds. A small "sticky-note box" holds about seven things for half a minute — like a phone number you are about to dial. A huge "library box" keeps facts and stories for years. Your brain also has two kinds of library books: "story books" about things that happened to you, and "fact books" of things you just know. Even if the story books are lost, you can still use the fact books and the skills you practiced.

## High-Yield Points

- **Three time courses:** sensory memory (fractions of a second to ~4 s), short-term/working memory (~15–30 s, limited capacity), long-term memory (indefinite).
- **The "magic number":** short-term memory capacity is classically cited as 7 ± 2 chunks, with modern estimates often closer to 4.
- **Working memory ≠ short-term memory:** working memory adds active manipulation; the classic model has a phonological loop, visuospatial sketchpad, episodic buffer, and central executive.
- **Serial position effect:** primacy (first items → LTM) and recency (last items → STM) reveal two separate stores.
- **Two memory types:** explicit/declarative (episodic + semantic; hippocampus-dependent) vs. implicit/nondeclarative (procedural, priming, conditioning; hippocampus-independent).
- **Amnesia dissociations:** H.M. could learn motor skills with no conscious memory of practicing — implicit memory survives when explicit memory fails.
- **Encoding–storage–retrieval:** forgetting can come from failure at any of the three stages; interference, not just time, drives decay.

## Key Terms

| Term | Plain-Language Definition | Why It Matters |
|---|---|---|
| Encoding | Converting experience into a neural representation | Nothing can be remembered if it is never encoded; attention gates what gets in |
| Storage | Maintaining a representation over time | Determines whether a memory survives seconds, days, or years |
| Retrieval | Accessing stored information for use | "Tip of the tongue" shows retrieval can fail even when storage succeeded |
| Sensory memory | Ultra-brief retention of raw sensory input | Gives the brain a moment to select what deserves attention |
| Short-term memory | Small-capacity, ~15–30 s store | Explains the phone-number effect and the limits of immediate recall |
| Working memory | Active, manipulable memory system | The bottleneck for reasoning, mental math, and multitasking |
| Long-term memory | High-capacity, long-duration store | The archive that supports knowledge, identity, and skill |
| Consolidation | Gradual stabilization of memories after learning | Why sleep and time matter; why new memories are fragile |
| Explicit (declarative) memory | Conscious recall of facts and events | Depends on the hippocampus; the memory type most affected by typical amnesia |
| Episodic memory | Personal events tied to time and place | Forms autobiographical identity; earliest type to decline in some dementias |
| Semantic memory | General knowledge without context | Stable facts ("Paris is the capital of France") |
| Implicit (nondeclarative) memory | Knowledge expressed through performance | Skills survive brain damage that destroys conscious recall |

## Example: The Exam-Night Phone Number

Picture yourself at midnight before an exam. A friend texts you a phone number for a study-group call; you repeat it aloud (rehearsal keeps it in short-term memory for ~20 seconds) and dial. Within a minute the number is gone — classic short-term memory. Meanwhile, you are also trying to learn the names of the cranial nerves. Each time you recite them, you are using working memory to hold and rearrange the list; because you space your practice and link the names to a mnemonic, the hippocampus consolidates the list into long-term memory. On the exam, the recency items you crammed last night are hazy (they never consolidated), but the material you practiced over three days comes back easily — primacy in action. Later, when you drive to the exam building without consciously thinking about the route, you are using procedural (implicit) memory: you can perform the route perfectly yet could not write a verbal description of every turn. One evening, three memory systems, three different rules.

## Common Confusions

| Do Not Confuse | With | Difference |
|---|---|---|
| Short-term memory | Working memory | STM just holds information briefly; working memory actively manipulates it (reordering, computing). Working memory = STM + processing. |
| Recency effect | Primacy effect | Recency reflects short-term memory (last items, forgotten if recall is delayed); primacy reflects long-term memory (first items, rehearsed more). |
| Episodic memory | Semantic memory | Episodic = personal events with time/place context; semantic = context-free facts. You can lose one while keeping the other. |
| Explicit memory | Implicit memory | Explicit is conscious and storable in words; implicit is expressed through performance. Amnesia spares implicit. |
| Forgetting | Encoding failure | "Forgetting" usually means retrieval or storage failure; much of what we call forgetting was never encoded in the first place (inattention). |
| Sensory memory | Short-term memory | Sensory memory holds raw perceptual input for under a few seconds with huge capacity; short-term memory holds attended, meaningful items for ~15–30 s. |
